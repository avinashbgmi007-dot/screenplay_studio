Filtered through both expert passes (design-director critique + deterministic WCAG audit) and scored on your five criteria: usability · screenplay immersion · diagnostic clarity · premium feel · scalability.

FIRST CHOICE

D1 — The Marked Proof

The only direction scoring high on all five criteria at once: the manuscript stays hero while the evidence sits an arm's length away in the same typographic language — ink, circled line numbers, margin annotations, sticky notes in the fold. It's the full sticky loop (highlight → note → pin → click locates the line) done natively, it migrates cheaply onto the shipped vertical shell, and its two flagged weaknesses are one-day fixes.

Why it wins: immersion and diagnostic clarity stop competing — that's the failure of the current Feedback View, solved at the geometry level rather than patched.

carried fixes: red-deconflation ✓ · graphite 4.53:1 ✓ · thinking pen ✓ · thread log retitled ✓

SECOND CHOICE — THE SAFE BET

D5 — The Atelier

The lowest-risk evolution: the shipped app's geometry refined (masthead→crown, dock→wall, panel→alcove, statusbar→rail) with the strongest hate-list compliance of the five — the benchcard now lives in a reserved grid slot so it structurally cannot cover the page, the alcove seats carry unfolding conversation threads, and partner identity has its own walnut hue that never borrows a severity color.

Why it's second, not first: safety purchased with a dressed-up chat rail and beige-on-beige premium risk — it refines what exists rather than answering the "feedback room shouldn't overwhelm" question as decisively as D1's margin language does.

carried fixes: ink-3 4.53:1 ✓ · terracotta/brass/patina AA ✓ · cardslot reflow ✓ · threads ✓ · walnut ✓

THE STRATEGIC PAIR

D1's language on D5's shell — the hybrid worth considering

The two directions are complementary, not competing: D5's zones are the cheapest migration target (near 1:1 with the shipped app), while D1's margin-annotation language is the strongest feedback presentation ever sketched for this product. A hybrid — Atelier geometry with the Marked Proof's margin evidence column and sticky loop — is the configuration the critic would bet on if you want evolution speed and presentation quality in one move.

Noted as an option, not pushed: the brief asked for five compositions and a recommendation, and the hybrid decision is yours to make after walking the rooms.

The critic's record.

passes: design-director critique (16 findings) · deterministic WCAG audit (57 pairs computed) · playwright smoke (25 state switches, 80 attribute blocks, 0 console errors) · all findings fixed and re-verified

What the critic caught and what was done about it —

  • P0 · D5 benchcard overlay — the finding card floated over the page's right edge at laptop widths → rebuilt as a reserved grid column beside the manuscript; overlap is now structurally impossible.
  • P0 · D3 focus/severity collision — interactive accent was the same hex as low-severity → interaction moved to clinical indigo #33366b; the severity ramp is now reserved for findings only.
  • P0 · D3 chartnote fake locate — promised "click to locate," had no handler → wired: opens the specimen drawer and centers the highlighted passage.
  • P1 · D2 severity-as-ink — flagged dialogue lines inherited severity colors (3.07–3.82:1, below AA for body text) → words now stay page-ink 13:1; severity lives on the dot, wash, and badge only.
  • P1 · D3/D4 chat-composition collision — two directions had the same side-by-side card chat → D3 restaged as a memo stack; compositions now genuinely distinct.
  • P1 · D2 dual Sameer in idea state → presence now exists in exactly one place per state; whisper dims only when the page is the centered focus.
  • P1 · D4 filmstrip scale — 50+ scenes would sprawl thousands of pixels → act-clustered reels; a feature collapses to ~4 clusters.
  • P1 · missing thinking states in D1/D3/D4 and missing selection tools in D2/D4 → all five now carry the full thinking treatment ("thinking it through" text preserved) and the creation half of the sticky loop.
  • P2 · D1 red-as-alarm tabs (active tab read as high severity) → neutral ink underline; D5 partner-as-finding (Sameer in brass) → walnut stain; fake ⌘K promises in D4/D5 → removed.
  • AA failures (D1 graphite 4.27, D3 ink-3 3.01, D5 ink-3 2.68 + severity ramp) → every flagged pair re-computed and verified ≥ 4.5:1 straight from the final files.
