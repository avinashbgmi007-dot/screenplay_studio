How to review each direction (3 minutes)

  1. R1 — upload: drop any file (or “open the sample project”). You must land Feedback-ready with Run Analysis as the hero action.
  2. R2 — click away: open Export ▾ or Sameer's menu, then click elsewhere or press Esc — everything dismisses.
  3. R3 — send one message: explore chips collapse to a hover/focus-reveal rail (Nocta, Beatwall) or minimize to a lens orb (Lumen). “···” restores.
  4. R4 — type three lines: the composer autogrows to ~40vh then scrolls internally; Enter sends, Shift+Enter breaks.
  5. R5 — coverage first-class: run analysis; the report reads top-to-bottom with verified quotes; the fix queue is a peer surface.
  6. Motion check: enable prefers-reduced-motion — every animation collapses to opacity fades, nothing breaks.
