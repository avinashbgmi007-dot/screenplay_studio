# requirements.lock.txt — exact pins for everything the declared dependencies
# pull in. Derived from a real, working environment; never hand-edited.
#
# HOW TO USE IT — as a *constraints* file, never as a second requirements list:
#
#     pip install ".[ci]"          -c requirements.lock.txt     # CI + dev
#     pip install -r requirements.txt -c requirements.lock.txt  # runtime only
#
# Why constraints rather than a flat `pip freeze` dump: requirements.txt and
# pyproject.toml decide WHICH packages exist; this file decides WHICH VERSIONS.
# `-c` only constrains packages pip was already going to install, so an entry
# nothing needs is inert. That matters because this file is derived on
# Windows / Python 3.13 while CI runs ubuntu-24.04 / Python 3.12 — `colorama`
# (pytest's win32 dependency) is a genuine pin here that simply never installs
# on the runner. A flat freeze would also have hard-coded this machine's
# 3.13-only resolution.
#
# Regenerate after changing a dependency: run the derivation in
# .workbuddy-ai/scratch/lockgen.py (it walks requires_dist, skipping `extra ==`
# markers, and records the version actually installed) — do not retype pins.
#
# DELIBERATELY NOT PINNED:
#   faster-whisper  — the opt-in `stt` extra. Not installed by default, so
#                     there is no verified version to record. Pin it when STT
#                     actually ships.
#   pytest-cov      — the `ci` extra. CI installs it; no development
#                     environment here has, so any version would be invented
#                     rather than measured. Pin it the first time a coverage
#                     run happens.
#   importlib-metadata / exceptiongroup / tomli / backports-asyncio-runner
#                   — all gated by `python_version < "3.10"` / `< "3.11"`
#                     markers, so they are correctly absent on 3.12+ and are
#                     not a gap in this file.
#
# tests/test_production_readiness.py enforces the contract: every line is an
# exact pin, every declared dependency is pinned or on the exception list
# above, no pin is older than the floor it has to satisfy, and no duplicates.
