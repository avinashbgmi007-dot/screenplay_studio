Screenplay Studio · redesign v4

Six Worlds

Six complete redesigns of the same product — same demo script (“The Second Shift”), same features, different answers. Each world is a full journey: shelf → upload → script desk → co-write → feedback → ideas. Use the review bar pinned to each world to jump rooms and flip the feedback report through its empty / running / complete states.

What is being finalized: layout, placeholder positions, interaction patterns, identity. Nothing here talks to a backend.
