Studio UX v2 — six directions

Six contrasting, fully interactive static designs for the redesigned studio. All six carry the same feature inventory and obey the same shell contract — three real rooms (Desk · Co-write · Feedback), feedback as a first-class room, Sameer dismisses outside-click/Esc everywhere, explore-chips collapse to a rail after your first message, and a composer that autogrows. Pick one identity; its placeholder map ships with it.

How to review each page (2 minutes)

  1. R1/R5 — feedback first? Upload-finished lands you in a full Feedback room; Run analysis / verdict are primary, never a corner pane.
  2. R2 — click away: open Export ▾ or Sameer's card, then click elsewhere or press Esc — it dismisses everywhere.
  3. R3 — send one message: explore chips collapse to a hover/focus rail; “···” restores them.
  4. R4 — type three lines: the composer autogrows to ~40vh then scrolls internally; Enter sends (demo reply streams word-by-word).
  5. Ctrl+K opens the command palette stub; ⚙ opens Settings; tabs switch Report ↔ Fix queue.
